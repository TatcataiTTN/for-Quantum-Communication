Quantum Communication over FSO Channels

An interactive self-study system built from every paper, textbook and report of the Quantum AI Lab: the Helstrom bound, Gamma-Gamma turbulence, multi-state modulation, practical receivers and physics-constrained neural surrogates.

Each document folder is one module: slides, worked examples, simulations, a quick quiz and a question bank (theory, code reading, code writing).
