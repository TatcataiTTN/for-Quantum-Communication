The Helstrom bound as a label for machine learning

Minimum error of two states
\[ P_e=\tfrac12\Bigl(1-\bigl\|\tfrac12(\rho_1-\rho_0)\bigr\|_1\Bigr)=\tfrac12\Bigl(1-\sum_i|\lambda_i|\Bigr) \]
  • \(\rho_0,\rho_1\)received states for bit 0 and bit 1
  • \(\lambda_i\)eigenvalues of \(\tfrac12(\rho_1-\rho_0)\)
  • \(\|\cdot\|_1\)trace norm: sum of absolute eigenvalues

For pure BPSK \(P_e=\tfrac12\bigl(1-\sqrt{1-e^{-4\bar n}}\bigr)\); at \(\bar n=1.1\) it equals \(0.003079\). An SDP solver needs about 85 ms per sample for this value, the surrogate only 0.118 ms.

📖 Plain-language explanation for beginners
The network learns a quantity with an exact answer: the oracle label is \(P_e\) computed by quadrature and eigenvalues.

The eight papers answer one question: how to make a parametric model output a valid quantum object that can be trained by gradient.

Supervised learning with oracle labels

Surrogate loss
\[ \mathcal L=\underbrace{\|\hat\rho_0-\rho_0\|_F^2+\|\hat\rho_1-\rho_1\|_F^2}_{\mathcal L_{\text{state}}}+\lambda\,\bigl(\hat P_e-P_e\bigr)^2 \]
  • \(\|\cdot\|_F\)Frobenius norm
  • \(\lambda\)Helstrom weight; the final runs use \(\lambda=1\)
  • \(\hat P_e\)error computed from \(\hat\rho\) by eigenvalues

Entries of \(\rho\) are of order \(10^{-3}\), so \(\|\cdot\|_F^2\) is tiny (about \(10^{-8}\)) and the state loss can be dominated by the Helstrom loss: track both terms separately.

📖 Plain-language explanation for beginners
The network sees two things, the true state matrices and the true error, and adjusts weights to match both.

Data re-uploading in a single-qubit classifier

Re-uploading circuit
\[ \mathcal U(\vec\phi,\vec x)=U(\vec\phi_N)U(\vec x)\cdots U(\vec\phi_1)U(\vec x) \]
  • \(U(\vec x)\)data loaded as a rotation
  • \(\vec\phi_i\)processing parameters of layer \(i\)

Eqs. (1), (2), p. 3: \(|\psi\rangle=\mathcal U|0\rangle\). The data enter many times, as every hidden neuron receives the input again.

📖 Plain-language explanation for beginners
A qubit cannot copy data, so we load the data again at every layer, like a neural network reusing the input at every neuron.

Compressed layers and measurement in the re-uploading classifier

Compressed layer
\[ \begin{aligned}L(i)&=U\bigl(\vec\theta_i+\vec w_i\circ\vec x\bigr)\\\vec w_i\circ\vec x&=(w_i^1x^1,w_i^2x^2,w_i^3x^3)\end{aligned} \]
  • \(\vec\theta_i,\vec w_i\)angles and weights to learn
  • \(\circ\)Hadamard product

Eq. (5), p. 4: compression halves the depth from \(2N\) to \(N\). Two-class rule: class A if \(P(0)>\lambda\).

📖 Plain-language explanation for beginners
Merging data loading and processing into one rotation gives a shorter circuit.

The weighted fidelity cost function

Weighted fidelity
\[ \chi^2_{wf}=\tfrac12\sum_{\mu=1}^{M}\sum_{c=1}^{C}\bigl(\alpha_cF_c(\vec x_\mu)-Y_c(\vec x_\mu)\bigr)^2,\quad F_c=|\langle\tilde\psi_c|\psi\rangle|^2 \]
  • \(Y_c\)target: 1 for the true class, \(1/3\) for others (tetrahedron)
  • \(\alpha_c\)class weights, learned with \(\vec\theta,\vec w\)

Eq. (9), p. 5. For the tetrahedron \(|\langle\tilde\psi_r|\tilde\psi_s\rangle|^2=0.3333\approx1/3\) (checked by code).

📖 Plain-language explanation for beginners
Each class is a point as far apart as possible on the sphere; the network learns to push data to its own class point.

The Cholesky head guarantees a valid state

Parametrisation by construction
\[ \rho=\frac{LL^{\top}}{\operatorname{Tr}(LL^{\top})},\quad L_{ii}=\operatorname{softplus}(v_{ii})+10^{-5},\quad L_{i>j}=v_{ij} \]
  • \(v\)linear output of the backbone (\(d^2\) numbers)
  • \(L\)lower-triangular matrix
  • \(\operatorname{softplus}\)\(\ln(1+e^x)\), always positive

For every \(v\): \(\rho=\rho^\top\), \(\rho\succeq0\) (since \(x^\top LL^\top x=\|L^\top x\|^2\ge0\)) and \(\operatorname{Tr}\rho=1\). No penalty term is needed.

Code sourcettn-12-08/model/heads.py: RealCholeskyPSDHead
📖 Plain-language explanation for beginners
Take any triangular matrix and multiply by its transpose: you always get a valid state matrix after dividing by the trace.

The differentiable Helstrom layer

Gradient through eigenvalues
\[ \Delta=\tfrac12(\hat\rho_1-\hat\rho_0),\quad \hat P_e=\tfrac12\Bigl(1-\sum_i|\lambda_i(\Delta)|\Bigr),\quad \frac{\partial\lambda_i}{\partial\Delta_{jk}}=u_i[j]\,u_i[k] \]
  • \(u_i\)unit eigenvector for \(\lambda_i\)
  • \(\Delta\)difference operator of the two states

This gradient (Giles, 2008) fails only when two distinct eigenvalues collide, not at \(\lambda_i=0\). The result is clamped to \([0,\tfrac12]\).

Code sourcettn-12-08/model/losses.py: helstrom_error_equal_priors (torch.linalg.eigvalsh)
📖 Plain-language explanation for beginners
The Helstrom error is computed inside the network from eigenvalues, so the network gets a learning signal straight from the quantity it must predict.

A PINN puts the governing equation into the loss

PINN loss
\[ \begin{aligned}\mathcal L&=\bigl|\operatorname{LME}(\tilde\rho,\dot{\tilde\rho})\bigr|^2+[\operatorname{Tr}\tilde\rho-1]^2\\&\quad+|\tilde\rho-\tilde\rho^\dagger|^2+|\tilde\rho(t_0)-\rho_i|^2\end{aligned} \]
  • \(\operatorname{LME}\)Lindblad residual
  • \(t\)network input: time

Four terms: physics, trace, Hermiticity, initial condition (Fig. 3, p. 240). Derivatives of the output with respect to the input come from automatic differentiation.

📖 Plain-language explanation for beginners
A PINN forces a network to obey a differential equation by penalising the equation residual in the loss.

Reinforcement learning for a real-time feedback agent

Policy gradient
\[ \Delta\theta\sim\nabla_\theta\bar R,\qquad R=\frac{V_{\rm ver}}{\Delta V}-n\lambda \]
  • \(\pi_\theta(a|s)\)policy: probability of action \(a\) given observation \(s\)
  • \(\lambda\)per-cycle penalty trading fidelity for length

Actions: idle, flip, terminate. The agent trains directly on the experiment (pp. 2 to 3).

📖 Plain-language explanation for beginners
The agent tries actions, is rewarded when the qubit reaches the right state quickly, and adjusts to earn more reward.

A worked three-dimensional Cholesky example

Raw three-dimensional outputs (lower-triangular entries) for \(v^{(0)}\) and \(v^{(1)}\): \(v^{(0)}=(0.9;0.4,0.6;-0.2,0.3,0.5)\), \(v^{(1)}=(0.8;-0.5,0.7;0.1,-0.3,0.4)\).

Two states after the Cholesky head
\[ \rho_0=\begin{pmatrix}0.4&0.129&-0.0644\\0.129&0.321&0.06\\-0.0644&0.06&0.28\end{pmatrix},\qquad \rho_1=\begin{pmatrix}0.364&-0.155&0.031\\-0.155&0.389&-0.101\\0.031&-0.101&0.248\end{pmatrix} \]

Eigenvalues of \(\rho_0\): 0.162, 0.342, 0.496, trace \(=1\). Helstrom bound of the pair: \(\hat P_e=0.30669\) (numpy, cross-checked in JS).

📖 Plain-language explanation for beginners
A handful of raw numbers become two valid state matrices and then a single error number.

A raw matrix may stop being a state

Symmetrised raw head
\[ \hat\rho=S-\frac{\operatorname{Tr}S-1}{d}I,\qquad S=\tfrac12(R+R^\top) \]
  • \(R\)raw \(d\times d\) output
  • \(S\)symmetric part

For \(R=\begin{pmatrix}0.2&0.9&0.7\\0.9&0.1&0.8\\0.7&0.8&0.3\end{pmatrix}\): trace after normalisation \(=1\) yet smallest eigenvalue \(=-0.6399\lt0\). It has unit trace but is no state, so a trace-norm \(P_e\) is meaningless.

Raw head trapRawMatrixHead is for ablation only: it does not guarantee PSD and can produce a wrong \(\hat P_e\).
📖 Plain-language explanation for beginners
Making a matrix symmetric with unit trace is not enough; a real state also has no negative eigenvalue.

Dual frames reduce estimator variance

Estimator and variance
\[ \begin{aligned}O&=\sum_k\omega_kM_k,\quad \omega_k=\operatorname{Tr}[OD_k]\\\operatorname{Var}&=\sum_k\operatorname{Tr}[\rho M_k]\,\omega_k^2-\langle O\rangle^2\end{aligned} \]
  • \(D_k\)dual frame of \(M_k\)
  • \(M_k\)POVM element

Eqs. (4), (5), (9), p. 3. One qubit, six Pauli elements, \(O=Z\), \(\rho=|0\rangle\langle0|\): the canonical dual gives variance \(2\); another dual that still reconstructs \(Z\) exactly gives \(\approx0\).

📖 Plain-language explanation for beginners
The same measurement data can be turned into an average in several ways; choose the least noisy one with no extra measurements.

Adaptive measurement optimises the POVM by gradient

Combining two independent estimates
\[ \alpha_{\rm opt}=\frac{\bar V_1}{\bar V_1+\bar V_2},\qquad \bar{\bar V}=\frac{\bar V_1\bar V_2}{\bar V_1+\bar V_2} \]
  • \(\bar V_t\)estimated variance of the \(t\)-th POVM
  • \(\alpha\)weight of the second estimate

P. 7. With \(\bar V_1=4\times10^{-4}\), \(\bar V_2=10^{-4}\): \(\alpha_{\rm opt}=0.8\), \(\bar{\bar V}=8e-05\), below both.

📖 Plain-language explanation for beginners
Measure while tuning how to measure for less noise, then blend all results by reliability.

Detector tomography by gradient descent

Softmax-constrained POVM
\[ \begin{aligned}&\min_\Pi\|P-F\Pi\|_F^2,\quad \Pi_{ij}\ge0,\ \sum_j\Pi_{ij}=1\\&\operatorname{softmax}(x)_i=\frac{e^{x_i}}{\sum_ke^{x_k}}\end{aligned} \]
  • \(F_{ij}\)Poisson probability of the probe coherent state
  • \(\Pi\)diagonals of the POVM elements

Eqs. (6), (8), p. 2. Variables: \(NM=5000\) (gradient descent) versus \(NM^2=1000000\) (constrained convex), a factor of \(200\) for \(N=25\), \(M=200\).

📖 Plain-language explanation for beginners
Instead of solving a heavy optimisation, we let the parameters descend gradually and softmax keeps the probabilities valid.

Accuracy and limits of gradient descent

POVM fidelity
\[ \begin{aligned}\mathcal F(\hat E,E)&=\frac{\operatorname{Tr}^2\sqrt{\sqrt E\,\hat E\sqrt E}}{\operatorname{Tr}[\hat E]\operatorname{Tr}[E]}\\E_n&=\sum_k\binom kn\eta^n(1-\eta)^{k-n}|k\rangle\langle k|\end{aligned} \]

Eqs. (10), (13), p. 3. Check with \(\eta=0.85\): \(\sum_nE_n=I\) (error 0), all eigenvalues \(\ge0\). The paper notes fidelity drops as \(M\) grows when the probe count does not.

Local-minimum trapSoftmax makes the problem non-convex and may stall in local minima, so run several initialisations (the paper uses 20).
📖 Plain-language explanation for beginners
Gradient descent is fast and light on memory, but no longer guarantees the best solution as a convex problem does.

Parametrising a POVM with a Stiefel isometry

POVM valid by construction
\[ E_n=W_n^\dagger W_n\succeq0,\qquad W=\begin{pmatrix}W_1\\\vdots\\W_N\end{pmatrix},\ \ W^\dagger W=\sum_nE_n=I_M \]
  • \(W_n\)block \(r_n\times M\), rank \(E_n\le r_n\)
  • \(W\)stacked matrix with orthonormal columns

Eqs. (16), (17), (21), pp. 6 to 7. Numeric test: an orthonormal \(6\times3\) matrix split into blocks \(W_1,W_2\): \(\|W_1^\dagger W_1+W_2^\dagger W_2-I\|_\infty=2.2e-16\), both \(W_n^\dagger W_n\) have eigenvalues \(\ge0.053\).

\( W\leftarrow W-\gamma\,\nabla^*_WL(W) \)

📖 Plain-language explanation for beginners
Like the Cholesky head for states, this parametrises measurements so that every parameter value gives a valid measurement.

PINNs for Lindblad dynamics in quantum memories

Storage cost
\[ \begin{aligned}\#\rho\ \text{entries}&=4^{N}\\\text{PINN}:\ 1\!\to\!10\!\to\!10\!\to\!10\!\to\!32&\Rightarrow 592\end{aligned} \]

P. 241: \(N=2,9,25\) qubits give \(4^N=16;\ 262144;\ 1125899906842624\) density entries; the PINN keeps \(592\) weights (paper: 592, three layers of 10 neurons), trained on 60 time points for 20,000 epochs.

📖 Plain-language explanation for beginners
A PINN makes sense when a real differential equation must be solved; our Helstrom problem has no such equation.

Summary and practical lessons

Take-aways

  2. The project network is a physics-constrained surrogate, not a PINN.
  3. 722 times faster, but trusted only for \(\bar n\le1.1\).
  4. Every number on the slides can be recomputed with data/verify/m13_verify.py.
Core formula
\[ \hat P_e=\tfrac12\Bigl(1-\bigl\|\tfrac12(\hat\rho_1-\hat\rho_0)\bigr\|_1\Bigr),\qquad \hat\rho=\frac{LL^\top}{\operatorname{Tr}LL^\top} \]
📖 Plain-language explanation for beginners
